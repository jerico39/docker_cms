インストールとセットアップ



拡張機能の検索: VSCodeを開き、左側のアクティビティバーから「拡張機能」アイコン（四角が組み合わさった形）をクリックします。検索バーに「Gemini Code Assist」と入力し、公式の拡張機能を見つけます。

インストール: 表示された拡張機能の「インストール」ボタンをクリックします。インストールが完了すると、アクティビティバーにGeminiのアイコンが追加されます。

→右下で黄色く 光ってる。


Googleアカウントでのサインイン: 新しく追加されたGeminiアイコンをクリックします。初回起動時には、Googleアカウントでのサインインを求められますので、画面の指示に従ってログインを完了させてください。



セットアップが完了すれば、すぐにAIの支援を受けられます。

チャット機能の利用: Geminiのパネルを開くとチャット画面が表示されます。ここに「Pythonで現在時刻を表示するコードを教えて」のように質問を入力すると、AIが回答を生成します。生成されたコードは、ワンクリックでエディタに挿入可能です。

コードに対する操作: エディタ上でコードの一部を選択した状態で右クリックすると、コンテキストメニューに「Gemini」の項目が表示されます。ここから「コードを説明する」「テストを生成する」などの操作を選択できます。

インラインでのコード補完: コードを記述していると、Geminiが後続のコードを灰色の文字で提案します。提案内容でよければ、Tabキーを押すだけでコードが確定されます。

このように、直感的な操作で利用を開始できるのがGemini Code Assistの魅力の一つです。まずは簡単な質問から試してみて、その能力を体感することをおすすめします。






VSCode Gemini CLIのインストール


VSCode Gemini CLIのインストール


Gemini Code AssistがGUIベースの直感的な操作を提供するのに対し、より柔軟でスクリプトへの組み込みも可能なのが「Gemini CLI」です。これは、コマンドラインインターフェース（CLI）を通じてGeminiと対話するためのツールで、特にターミナルでの作業に慣れている開発者にとっては強力な武器となります。

インストールには、Node.jsとnpmがコンピュータに導入されている必要があります。これらの環境が整っていれば、ターミナル（またはコマンドプロンプト）から簡単なコマンド一つでインストールが完了します。

以下のコマンドを実行してください。

npm install -g @google/generative-ai

このコマンドにより、Gemini CLIがグローバルにインストールされ、どのディレクトリからでもgeminiコマンドが使えるようになります。

インストール後、初めてgeminiコマンドを実行すると、Googleアカウントとの連携設定が求められます。設定が完了したら、VSCodeとの統合を有効化するために、Gemini CLIのプロンプトで次のコマンドを実行するのがおすすめです。

/ide install

これを実行することで、CLIがVSCodeエディタの状態（開いているファイルや選択範囲など）を認識できるようになり、より文脈に沿った的確な応答が可能になります。このように、CLIをセットアップすることで、ターミナルから離れることなく、コーディング作業をAIに支援させることが実現します。
